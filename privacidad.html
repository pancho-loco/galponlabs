Política de Privacidad

Aplicación: Osiris — asistente personal self-hosted sobre Hermes Agent.

1. Alcance

Esta aplicación es de uso estrictamente personal y privado. La utiliza un único titular, sobre su propia cuenta de Google. No es un servicio ofrecido al público, no tiene usuarios terceros ni registro abierto.

2. Qué datos accede

Con el consentimiento explícito del titular, la aplicación solicita acceso a los siguientes datos de su propia cuenta:

  • Gmail (solo lectura, envío y modificación): leer correo, enviar respuestas y aplicar etiquetas.
  • Google Calendar: leer y crear eventos y recordatorios.
  • Google Drive, Docs y Sheets: leer y escribir archivos del titular.
  • People API (solo lectura): consultar contactos para resolver destinatarios.

3. Dónde se guardan los datos

Los datos no salen del entorno del titular. El token de acceso OAuth y cualquier copia de trabajo se almacenan cifrados en disco en el servidor personal del titular (infraestructura propia, autoalojada). No existe ningún servidor intermediario operado por terceros.

4. Con quién se comparten

Con nadie. No se venden, alquilan, ceden ni comparten datos con terceros. No se usan para publicidad, perfilado ni entrenamiento de modelos.

Únicamente se transmiten consultas a las APIs de Google, necesarias para cumplir la función solicitada (por ejemplo, leer un correo o crear un evento). El contenido puede procesarse a través de proveedores de modelos de lenguaje (LLM) configurados por el propio titular, con la sola finalidad de ejecutar la instrucción que él mismo da.

5. Retención

No se mantiene una copia permanente del correo, los archivos o el calendario. Los datos se leen en el momento de la consulta. El titular puede borrar el token y los datos locales en cualquier momento.

6. Seguridad

El acceso se realiza mediante OAuth 2.0 con tokens revocables. El servidor es privado, no expuesto públicamente, y las credenciales no se comparten con terceros.

7. Revocación y derechos del titular

El titular puede revocar el acceso en cualquier momento desde myaccount.google.com/permissions, o eliminando el token local. Al revocarlo, la aplicación pierde todo acceso de inmediato.

8. Uso limitado (Limited Use)

El uso que esta aplicación hace de la información recibida de las APIs de Google cumple con la Política de Datos de Usuario de los Servicios API de Google, incluidos los requisitos de Uso Limitado (Limited Use).
